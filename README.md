# CampaignIQ – Marketing Campaign Analysis

Marketing campaign performance analysis using Python, SQL, and Power BI.

## Project Overview

CampaignIQ is an end-to-end data analysis project focused on understanding marketing campaign performance and customer engagement.

The project uses Python for data cleaning and exploratory analysis, SQL for data analysis, and Power BI for interactive visualization and dashboard development.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL / MySQL
- Power BI
- DAX

## Analysis Performed

- Cleaned and prepared marketing campaign data using Python
- Performed exploratory data analysis (EDA)
- Analyzed campaign performance and customer engagement
- Used SQL to query and analyze campaign data
- Evaluated key marketing performance metrics
- Created an interactive Power BI dashboard
- Presented insights through data visualizations

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Analysis
4. Dashboard Development
5. Business Insights

## Project Files

- `CampaignIQ.ipynb` – Python data cleaning and analysis
- `CampaignIQ-sql.sql` – SQL analysis queries
- `CampaignIQ.pbix` – Power BI dashboard

## Key Objective

The objective of this project is to analyze marketing campaign data and transform raw data into meaningful insights that can support better campaign performance evaluation and business decision-making.
